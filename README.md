# Tannu Speak English AI

Android starter project for a free English-learning app prototype.

## Current features
- Home screen
- Daily Lesson button
- Vocabulary button
- Pronunciation Practice button
- Speak with AI placeholder
- My Progress placeholder

## Build
Open this folder in Android Studio and let Gradle sync. Then run the `app` configuration on an Android phone/emulator.

The next version can add Speech-to-Text, text-to-speech, lesson storage, progress tracking, and an AI conversation API.
